# Roadmap

Planned/possible extensions include:

- canonical numerical `k, E(k)` input independent of plotting,
- direct parsers/adapters for VASP, Quantum ESPRESSO, and SIESTA,
- explicit spin-channel and SOC-center reduction policies,
- continuity/Hungarian band matching for numerical references,
- real held-out k-point validation,
- optional effective-mass and VBM/CBM-location terms,
- more general image color segmentation and optional manual bounding boxes,
- uncertainty estimates tied to raster resolution,
- multi-structure fitting for transferability.

Items listed here are roadmap ideas, not implemented features unless they also appear in the current CLI help and tests.
